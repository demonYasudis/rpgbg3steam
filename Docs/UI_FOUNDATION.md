# WP-33 — основа интерфейса

Реализация: 15.10.2026, Unity 6000.2.8f1.

## Технология и запуск

Runtime UI Toolkit уже входит в проект через `com.unity.modules.uielements`.
Выбран для новых экранов: retained UI, USS, масштабируемая компоновка,
клавиатурный фокус и единый источник состояний элементов. Новых пакетов нет.
IMGUI остаётся рабочей презентацией до приёмки следующих UI-пакетов.

Откройте `Assets/Scenes/TacticalPrototype.unity`, включите Play, перейдите
в «Старый UI» из отряда WP-34 и нажмите «Мастерская UI (WP-33)» внизу справа.
Внутри доступны RU/EN, три образца вкладок,
четыре иллюстрированные карточки, подсказки, состояния кнопок и тестовое окно.
Вкладки пока демонстрируют компонент; игровые экраны добавляются в WP-34–41.
Кнопка «Старый UI / Esc» возвращает прежний экран.

`UiFoundation` создаёт один UIDocument и один PanelSettings на сцену.
Опорное разрешение 1280×720; ScaleWithScreenSize, match 0.5. Центральная область
имеет вертикальную прокрутку при недостатке высоты. Используется встроенный
LegacyRuntime.ttf с кириллицей. Язык берётся из существующего Localization;
игровые ID и сохранения не меняются. Экран намеренно подписан как мастерская,
чтобы демонстрационные карточки не принимались за настоящий состав гильдии.

## Повторное использование

- `Assets/Scripts/UI/UiComponents.cs`: независимые Card, Tab, Button, Tooltip, Modal.
- `Assets/Resources/UI/Foundation.uss`: рамки, normal/hover/pressed/disabled,
  selected и focus; выбранное состояние отличается также толщиной рамки.
- `Assets/Resources/UI/FoundationTheme.tss`: встроенная тема runtime Unity.
- `Assets/Resources/UI/FoundationPanel.asset`: настройки с заранее назначенной темой;
  runtime создаёт копию, не меняя общий asset.
- `UiIcon.cs`: отдельные векторные иконки золота, экипировки и похода,
  не зависящие от наличия символов в шрифте.
- `Assets/Resources/UI/Art/`: отдельный зал и четыре портрета; текст рисует UI.
- `UiArtImporter`: иллюстрации с bilinear-фильтрацией без mipmaps. Это масштабируемая
  живописная графика меню; Point-фильтрация боевых атласов не меняется.

Существующие Hero art V2 используются как ориентир идентичности классов:
серебряные доспехи/бордовый плащ, тёмный капюшон, рыжие волосы/зелёный плащ,
седой маг/синий плащ. Готовые атласы не перегенерированы. Общий источник миниатюр
и анимации подключаются в WP-34/37.

## Ввод и жизненный цикл

UiInputGate принадлежит сцене, без глобального singleton. Открытая мастерская
владеет всем экраном; старые IMGUI-экраны не рисуют интерактивные элементы.
PlayerUnitController объединяет существующую блокировку старых окон с новым gate,
поэтому закрытие нового окна не снимает блокировку старого. HexGridInteraction
отклоняет указатель; Update не обрабатывает zoom/pan. Кадр закрытия тоже поглощается,
чтобы клик по кнопке возврата не попал на карту.

Модальное окно выключает фоновые элементы, переводит фокус на закрытие,
удерживает Tab и сначала обрабатывает Esc. Закрытие возвращает фокус открывшей
кнопке. Следующий Esc закрывает мастерскую. Перестройка дерева удаляет старые
обработчики вместе с элементами; глобальных подписок нет. Отключение компонента
освобождает ввод; созданные UIDocument/PanelSettings удаляются при уничтожении.
Компоненты не вызывают RNG, команды гильдии или смену схемы сохранения.

## Проверки

`GuildTactics.Editor.UiFoundationChecks.RunBatch` запускать с `-batchmode`,
без `-quit` и `-nographics`. Проверяет реальные панели в Play Mode, оба языка,
геометрию текста, 1280×720 и 1920×1080 через targetTexture панели, фокус/Esc,
действительные NavigationSubmitEvent кнопок, блокировку команд боя/кликов карты,
20 переключений и один вызов обработчика закрытия, восстановление ввода.
Снимки: `Logs/wp33-1280-ru.png`, `wp33-1280-en.png`, `wp33-1920-ru.png`,
`wp33-1920-en.png`, `wp33-1920-modal-ru.png`.

Общая регрессия: `GuildTactics.Editor.HexPresentationChecks.RunBatch`.
Проверки модели не заменяют визуальную инспекцию снимков и работу мышью/клавиатурой.
Результаты текущего прогона и ограничения см. в TECHNICAL_NOTES.md.
